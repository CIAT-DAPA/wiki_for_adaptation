Import SOPs

Upload the SOP masterfile (.xlsx). Each row of the SOPs sheet creates or updates an Indicator → Metric → SOP. Rows are matched by their stable IDs (indicator_id / sop_id), so re-uploading updates existing pages instead of duplicating them.

  • Dry run — checks the file and shows what would be created/updated/errored, without saving anything. Use it to validate your template first.
  • Import as drafts — creates the pages unpublished, for review. Note: a SOP only appears on the site once its Indicator and Metric are also published, so publish the branch top-down (Indicator → Metric → SOP).
  • Import and publish — creates and publishes the whole Indicator → Metric → SOP branch at once (visible immediately).
